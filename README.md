# ETF 轮动

25 只宽基和行业 ETF。每个月末按过去 20 日的动量排序，买最强的 3 只，持有一个月，下个月末再换。2019 到 2026 年回测，含交易成本，年化 11.4%，同期沪深300ETF 是 7.7%。

超额不多，3.7 个百分点。但这是我能找到的第一个真能落地的策略——ETF 一手几百块，一千块就能跟着跑。

## 回测结果

| | 策略 | 沪深300ETF |
|---|---|---|
| 年化收益 | 11.43% | 7.67% |
| 夏普 | 0.53 | 0.46 |
| 最大回撤 | -47.0% | -44.8% |
| 样本内年化 | 14.85% | 10.98% |
| 样本外年化 | 8.30% | 4.18% |

样本外衰减了但没崩，这点和之前那个个股因子策略不一样。

## 2026 年 7 月那次

净值从 3.48 掉到 2.78，一周跌了 20%。

查下来不是数据问题。7 月 1 日策略调仓进 512480（半导体）、159995（芯片）、588000（科创50），因为这三只 6 月涨得最猛。然后 7 月芯片板块崩了，三只分别跌 34%、34%、26%。

这是动量策略躲不开的毛病：买涨得最好的，而涨得最好的往往情绪最热，反转时跌得最狠。回测里这个坑被完整记录下来了，没有删。

## 怎么跑

```bash
pip install pandas numpy matplotlib requests
python download_etf.py   # 拉 25 只 ETF 的日线，约 10 秒
python run_etf.py        # 回测 + 参数扫描 + 图表
```

结果在 `reports/`：`report.md` 是文字报告，`nav.png` 是净值曲线。

## 参数敏感性

试着扫了动量窗口和持仓数：

| 窗口 / 持仓 | 年化 | 样本外 |
|---|---|---|
| 10 日 / 3 只 | 1.4% | -3.4% |
| 20 日 / 3 只（默认） | 11.4% | 8.3% |
| 60 日 / 5 只 | 12.4% | 11.8% |

10 日完全无效，20 日以上才行。60 日那组看着更好，但这是事后挑的，按纪律不能用——默认参数在跑之前就定了。

## 一千块怎么用

`docs/1000元执行方案.md` 里写了完整的。

先说结论：**先查券商佣金有没有最低 5 元**。有的话 1000 块做不了——319 笔交易、每笔 5 元，7.8 年费用 1595 元，而本金只有 1000，年化 **−24.0%**。

免五渠道（万 0.5–万 1）才能做，年化约 10.8%。但 1000 块还买不起 510300/510500（一手要 418/686 元），11% 的调仓会缺标。真正的门槛是 **1 万**以上——5000 块只有 8.3%，比沪深300躺着不动（7.67%）多不了多少。

执行时**只在标的更换时交易，不要每月等权再平衡**，能多赚 0.5 个百分点。测算用 `python test_commission.py`，细节见 `docs/1000元执行方案.md`。

## 局限

- 只有 25 只 ETF，覆盖不到全部行业
- 2020 年后才上市的 ETF（科创50、光伏、新能源车）早期没有数据
- 没做择时，只有「最强动量小于 0 就空仓」这一条粗糙规则
- 回撤大，2022 年 -37%，2026 年 7 月单周 -20%
